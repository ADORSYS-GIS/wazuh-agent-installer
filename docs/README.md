# Wazuh Agent Installer Documentation

Documentation for the Wazuh Agent Installer, a desktop GUI application that provides a guided interface for installing and configuring a full Wazuh security agent stack on Linux, macOS, and Windows. This documentation is for developers, maintainers, and contributors.

The repository follows the organization documentation standard ([DOCS-STANDARD.md](https://github.com/ADORSYS-GIS/wazuh/blob/main/docs/DOCS-STANDARD.md)), which maps documentation folders to Software Development Life Cycle (SDLC) phases.

## SDLC map

| Phase | Folder | Contents |
| :--- | :--- | :--- |
| Design | [architecture/](./architecture/README.md) | System topology, Tauri IPC architecture, security & privilege model |
| Decision | [adr/](./adr/README.md) | Architecture Decision Records (ADRs) |
| Build | [development/](./development/README.md) | Setup, development workflows, branding and theme customization |
| Test | [testing/](./testing/README.md) | Unit tests, test suites, CI validation gates |
| Operate | [operations/](./operations/README.md) | Packaging, updates and auto-restart, troubleshooting and support runbook |
| Reference | [reference/](./reference/README.md) | Configuration options, endpoints, CLI and environment variables |
